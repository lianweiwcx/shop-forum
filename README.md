# 在线商城论坛平台 — 开发文档

## 1. 项目简介

一个面向普通用户的「在线商城 + 社区论坛」一体化平台：

- **商城**：用户可以浏览商品；支持商家入驻后发布、管理自己的商品。
- **社区**：所有登录用户都可以发帖、回帖，进行交流互动。

整体定位为轻量级应用，功能够用即可，不追求过于复杂的业务。

---

## 2. 技术选型

| 项目       | 选型说明                         |
| ---------- | -------------------------------- |
| 后端语言   | PHP（推荐 PHP 8.x）              |
| 数据库     | MySQL（推荐 5.7+ / 8.0）         |
| 前端       | 原生 HTML + CSS + 少量 JS        |
| 服务器     | Apache / Nginx（支持 PHP-FPM）   |
| 开发模式   | 轻量分层（DAO + Service + 页面） |

> 说明：不引入大型框架，使用原生 PHP 分层写法，降低复杂度，便于维护与部署。

---

## 3. 角色与权限

| 角色     | 说明                                           | 主要权限                                   |
| -------- | ---------------------------------------------- | ------------------------------------------ |
| 游客     | 未登录用户                                     | 浏览商品、浏览帖子                         |
| 普通用户 | 注册并登录的用户                               | 发帖、回帖、下单/收藏（本期先做浏览交流）  |
| 商家     | 通过入驻申请的普通用户                         | 发布商品、编辑/下架自己的商品、查看订单    |
| 管理员   | 平台运营人员                                   | 审核商家入驻、管理商品/帖子、处理举报       |

---

## 4. 功能模块

### 4.1 用户模块
- 注册、登录、退出登录
- 个人中心（昵称、头像、资料编辑）
- 申请成为商家（入驻）

### 4.2 商城模块
- 商品列表 / 商品详情浏览（游客可见）
- 商家入驻申请与审核
- 商家发布商品（标题、价格、库存、图片、描述、分类）
- 商家管理自己的商品（编辑、上/下架、删除）
- 商品分类、搜索（按名称/分类简单筛选）

### 4.3 社区模块
- 帖子列表 / 帖子详情
- 发布帖子（标题、正文、配图、话题分类）
- 回复帖子（楼层评论）
- 帖子管理（作者可删除自己的帖子/回复）

### 4.4 管理后台（简化版）
- 商家入驻审核
- 商品 / 帖子 违规下架
- 用户管理

## 5. 数据库设计

> 命名规范：表名使用小写蛇形（snake_case），主键统一为 `id`（自增），时间字段统一为 `created_at` / `updated_at`。

### 5.1 用户表 `users`
| 字段         | 类型            | 说明                         |
| ------------ | --------------- | ---------------------------- |
| id           | INT AUTO_INCREMENT | 主键                       |
| username     | VARCHAR(50)     | 登录账号（唯一）             |
| password     | VARCHAR(255)    | 密码（bcrypt/哈希存储）      |
| nickname     | VARCHAR(50)     | 昵称                         |
| avatar       | VARCHAR(255)    | 头像路径（可空）             |
| role         | TINYINT         | 0 普通用户 / 1 商家 / 2 管理员 |
| status       | TINYINT         | 0 正常 / 1 禁用              |
| created_at   | DATETIME        | 注册时间                     |

### 5.2 商家入驻表 `merchants`
| 字段         | 类型            | 说明                             |
| ------------ | --------------- | -------------------------------- |
| id           | INT AUTO_INCREMENT | 主键                         |
| user_id      | INT             | 关联 users.id                    |
| shop_name    | VARCHAR(100)    | 店铺名称                         |
| contact      | VARCHAR(100)    | 联系方式                         |
| description  | TEXT            | 店铺简介                         |
| audit_status | TINYINT         | 0 待审核 / 1 通过 / 2 拒绝       |
| created_at   | DATETIME        | 申请时间                         |

### 5.3 商品表 `products`
| 字段         | 类型            | 说明                             |
| ------------ | --------------- | -------------------------------- |
| id           | INT AUTO_INCREMENT | 主键                         |
| merchant_id  | INT             | 关联 merchants.id                |
| title        | VARCHAR(120)    | 商品标题                         |
| price        | DECIMAL(10,2)   | 价格                             |
| stock        | INT             | 库存                             |
| category     | VARCHAR(50)     | 分类                             |
| image        | VARCHAR(255)    | 主图路径                         |
| description  | TEXT            | 商品描述                         |
| status       | TINYINT         | 0 下架 / 1 上架                  |
| created_at   | DATETIME        | 发布时间                         |

### 5.4 帖子表 `posts`
| 字段         | 类型            | 说明                             |
| ------------ | --------------- | -------------------------------- |
| id           | INT AUTO_INCREMENT | 主键                         |
| user_id      | INT             | 发帖人（关联 users.id）          |
| title        | VARCHAR(120)    | 标题                             |
| content      | TEXT            | 正文                             |
| topic        | VARCHAR(50)     | 话题分类                         |
| image        | VARCHAR(255)    | 配图（可空）                     |
| status       | TINYINT         | 0 正常 / 1 已删除                |
| created_at   | DATETIME        | 发布时间                         |

### 5.5 回复表 `replies`
| 字段         | 类型            | 说明                             |
| ------------ | ----------------| --------------------------------- |
| id           | INT AUTO_INCREMENT | 主键                         |
| post_id      | INT             | 关联 posts.id                    |
| user_id      | INT             | 回复人（关联 users.id）          |
| content      | TEXT            | 回复内容                         |
| status       | TINYINT         | 0 正常 / 1 已删除                |
| created_at   | DATETIME        | 回复时间                         |

## 7. 关键业务流程

### 7.1 商家入驻流程
1. 用户注册并登录。
2. 在「个人中心 → 申请入驻」填写店铺信息提交。
3. 写入 `merchants` 表，`audit_status = 0`（待审核）。
4. 管理员在后台审核：通过则 `users.role` 置为 1（商家），拒绝则通知用户。
5. 商家登录后可见「发布商品」入口。

### 7.2 发布商品流程
1. 商家进入「发布商品」页，填写标题/价格/库存/分类/图片/描述。
2. 提交后写入 `products` 表，`status = 1`（上架）。
3. 商品出现在商城列表，游客/用户可浏览详情。

### 7.3 发帖交流流程
1. 登录用户进入社区，点击「发帖」。
2. 填写标题、正文、话题、配图后提交，写入 `posts` 表。
3. 其他用户在帖子详情页点击「回复」，写入 `replies` 表。
4. 作者可删除自己的帖子或回复。

## 9. 开发阶段划分

1. **阶段一：基础骨架**
   - 搭建目录结构、数据库配置、用户注册登录。
2. **阶段二：商城**
   - 商家入驻申请与审核、商品发布与浏览。
3. **阶段三：社区**
   - 发帖、回帖、帖子列表/详情。
4. **阶段四：管理后台**
   - 商家审核、商品/帖子管理。
5. **阶段五：打磨**
   - 图片上传、搜索筛选、基础样式美化。

## 10. 安全与注意事项

- 密码必须哈希存储，禁止明文。
- 所有用户输入使用预处理语句（PDO prepare）防止 SQL 注入。
- 文件上传需校验类型与大小，避免上传可执行文件。
- 后台操作需校验管理员身份，防止越权访问。
